# InfraSpace Multi-Resource Logistics

让配送中心和搜集中心同时处理多种物资。

## 功能

- 顶部直接排列所有已选物资图标，末尾的 `+` 用于添加物资。图标会标红：该物资没有配对的搜集中心或配送中心，或者配对中心之间没有货车路径。鼠标放上图标可看到具体的配对中心名称；到不了的会写成“货车无法从某搜集中心开到某配送中心”。左键把图标变成灰色，这件物资只保留库存，不再搜集、配送或转给配对中心；再点一次恢复。下面的配对中心行在货车到不了时换成车站那种红色背景。开放视图里，这种中心的建筑头顶会弹出警示。
- 右键物资图标可移除；存在库存或在途车辆时会先弹出确认框。
- 原版“存储”区域改为物资列表。每一行是物资图标、各行等长的容量滑块，以及当前库存/当前容量。斜杠上下对齐，位数不够时不在前面补零。滑块画框按半径滑块的方式固定，拖动时只拉开填充，不把画框或进度条拉变形。左键库存数字切换地图和半径滑块当前显示的物资。库存图标的提示不再写左右键操作；物资名称右边显示近 1 分钟的每分钟流入和流出，数字按 3 位用空格补齐并靠右。列表少显示一行，免得底部操作栏挡住添加配对的按钮。鼠标移到中心建筑上会显示每种物资最近 1 分钟的每分钟流入、流出，以及库存百分比；百分比固定三位，不足时前面留空，不补 0。只有最近 1 分钟运入低于运出的 90%，并且库存低于目标容量的 50% 时，建筑头顶才弹出警示；这时提示里的这一行标红，物资图标和列表背景也改成和没路时一样的红。
- 每种已选物资使用独立库存槽和独立容量，单项最高 2000。
- 不论当前选了一种还是多种物资，搜集、配送和连接都走本 Mod。从多种减回一种时，会按剩下的物资重新连接。
- 范围内生产建筑凑满一整车后，会把已选物资送往还有空位的搜集中心。仅存储的物资不发车。
- 打开中心时地图一次只显示一种物资，默认是主物资。库存列表里左键库存数字可以切换，当前数字会高亮，半径滑块、数字和地面的圆一起换成这种物资自己的半径。拖动滑块只改变当前物资的覆盖范围。左键图标仍是仅存储，右键仍是移除。这种物资在自己的半径内且货车能到为绿色，半径内没路为红色，半径外但仍生产或消耗它为黄色。仅存储的物资不给建筑上色。鼠标放在建筑上会列出这座中心哪些物资经过它，以及能送到、没路、半径外还是仅存储。范围内货车到不了的建筑不会挂上配送中心，继续由公共供需配送。
- 某种产出被搜集中心覆盖时，仍优先留给还有一整车空位的搜集中心。范围内的搜集中心都装不下一整车时，这一车按公共需求送出。勾选了该物资的仓库即使已经挂在配送中心上，只要有路也会接收。
- 工厂配方的输入图标会列出来途数量和来源，并写明由哪座配送中心配送，或交给公共供需；旁边的配送图标使用同一说明。输出图标会列出在途去向，以及送往哪座搜集中心或交给公共供需。搜集中心箭头的说明改为优先搜集中心，其次全局处理。工业机器人和高科技工具的提示会显示在途货车，以及当前是暂不请求、由配送中心配送，还是交给公共供需。这两种耐久降到一成时就开始请求 1 个，不必等到几乎用完。
- 配送中心只向货车能够到达的消费建筑配送已选物资。读档时只登记范围，进入游戏后再逐个确认道路；确认完成前这些建筑仍走公共供需。
- 已连接的搜集中心与配送中心会转运双方共同选择的物资。
- 物资选择随游戏存档保存。
- 配送按原版上报的需求分数排序，再结合库存缺口派车。
- 物流中心出口车辆会延后执行必要变道，减少出口附近交叉阻塞。
- 物流中心自带的多车道出口放车时，优先放在接到主路后、到下一个路口不用再变道的那条车道上。三条都不符合，或这条车道没有空位时，仍按原版从有空位的车道出发。

## 不属于本 Mod 的功能

车站轨道/道路端口方向、镜像和列车出生轨道已经拆到 `InfraSpaceStationTools`。

## 存档状态

以下数据由 `MultiResourceLogisticsMod` 随存档保存：

- 每个中心选择的物资名称；
- 每种物资的独立容量；
- 每种物资的覆盖半径；旧存档没有这项时，全部物资沿用中心原来的半径；
- 每种物资是否仅存储；旧存档没有这项时全部按正常搜集和配送处理；
- 为迁移旧存档暂时保留的车站端口字典。

旧车站字典只供 StationTools 一次性导入，不再驱动车站功能。

## 构建

项目默认引用：

`F:\SteamLibrary\steamapps\common\InfraSpace\InfraSpace_Data\Managed`

如果游戏安装位置不同，可通过 `GameManagedPath` 属性覆盖：

```powershell
dotnet build .\InfraSpaceMultiResourceLogistics.csproj -c Release -p:GameManagedPath="D:\Games\InfraSpace\InfraSpace_Data\Managed"
```

## 安装

把以下文件复制到：

`%USERPROFILE%\AppData\LocalLow\Dionic Software\InfraSpace\mods\InfraSpaceMultiResourceLogistics`

- `InfraSpaceMultiResourceLogistics.dll`
- `0Harmony.dll`
- `config.json`

进入游戏后，在模组列表启用该模组。

## 兼容性

- 兼容等级：C（需要 Mod 保持完整语义）。
- 卸载后存档可能仍能打开，但额外物资、容量和多物资调度会丢失或降级。
- 首次迁移请使用备份存档验证。

## 旧标识

程序集、配置名和根命名空间统一为 `InfraSpaceMultiResourceLogistics`。旧 `InfraSpaceMultiLogistics` 存档必须先使用仓库迁移工具生成副本。
