# InfraSpace Construction Tools

面向建造阶段的原版存档安全工具包。

## 功能

### 批量移动

按 `Ctrl+M` 进入批量移动模式，拖框选择建筑和框内道路；预览期间可使用游戏的镜头旋转键旋转 90 度，预览有效时左键确认，右键或 `Esc` 取消。道路会在选框边缘裁切，建筑组会整体选中。

### 蓝图复制

按 `Ctrl+C` 进入复制模式，拖框选择建筑和道路。预览期间可使用游戏的镜头旋转键旋转 90 度，按住 `Shift` 微调位置。

复制调用原版建造与资源结算，并复制已支持的建筑配置。其他 Mod 可通过可选 Harmony 后缀复制自己的配置。

### 道路磁吸开关

施工道路时按 `H` 切换是否吸附到已有道路。关闭磁吸只忽略已有道路节点、边和道路碰撞体，网格对齐保持有效。

### 产率依赖连线

移动或放置建筑时，原版黄色连线指向能提高它产率的邻居。本 Mod 另外画出蓝色连线，指向靠它提高产率的建筑，线上的百分比与原版相同。两边互相提高时，蓝线会稍稍错开，避免和黄线重叠。没有进入移动或放置时，普通点击不显示这两条线；在已建成建筑上按住鼠标左键约半秒后才显示，松开后消失。

### 铁路链式升级

使用铁路替换工具时按住 `Shift`，升级与当前铁路连通且可编辑的铁路，价格提示显示总成本。

## 兼容性

- 不保存自定义建筑或网络类型；
- 最终世界对象均由原版系统创建；
- 兼容等级：A（原版存档安全）。

## 技术说明

程序集、配置名和根命名空间均为 `InfraSpaceConstructionTools`，入口类型为 `InfraSpaceConstructionTools.ConstructionToolsMod`。旧 `AreaMove` 与 `RoadSnap` 存档入口由仓库迁移工具合并。
