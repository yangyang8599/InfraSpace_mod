# InfraSpace Production Insights

增强原版生产概览面板的只读分析 Mod。

## 功能

### 隐藏全零行

查看地区数据时，如果某项资源显示的就业、生产、消费均为零，则隐藏该行。全局视图不做此筛选。

### 列表合计

生产概况分成三个统计。未选地区是全局统计：产量、消费、颜色和顺序保持原版，并保留合计、工人「总数/每座」、图标建筑数和点击定位。工业机器人和高科技工具的消费加上有效配送内的磨损，数字加下划线，提示仍说明座数和每分钟 0.048。选中地区且未开规划模式时是地区统计：三个数字都是 0 才隐藏；消费列保留原版数字（含住宅），有居民消耗时加下划线和提示；效率行用工人、原版电耗（含住宅）和没有生产建筑的原料，原料数量去掉居民消费，净产出 = 产量 − 不含居民的消费，磨损要扣，居民吃掉的最终产物不减净产出。选中地区并勾选规划模式时是规划模式统计。点产量或消耗列表头的图标，可分别在原版、这一拍、最近连续 1 分钟之间切换，开关不写入存档，只在全局统计和地区统计中生效。这一拍约 0.2 秒，只统计这次采样里正在运转的工厂；连续 1 分钟是把这些速率在最近 60 秒里取平均，停下的时段按 0 计入。消耗再加居民消耗和磨损，电力仍用原版。效率行跟着这两列的数字走，居民仍不计入净产出。规划模式打开时点这两个图标不会切换，只提示要先关掉规划模式。

每个资源图标底部显示正在生产它的建筑数量，合计行的图标位置显示这些数量之和。未选择区域时按全图计数；选中区域后只计该区域内的建筑。供电建筑计入电力。同一座建筑若产出多种物资，会分别计入每种物资。

### 规划模式统计

地区勾选后才能打开「规划模式」，它左边是「无产原矿」，再左边是「高科工具」。三个开关都有用法提示。规划模式的产出列按当前建筑数量和配方计算，不看开工。已安装加成和覆盖中的土壤富集站始终计入；「高科工具」打开后，已安装的高科技工具按 1.5 倍计入，不管有没有送到，没安装的不假设。消耗列从最终产物倒推。没勾「无产原矿」时倒到开采物；勾上后只走已经建好的生产建筑，没建的物品当原料。有机废料始终是终点。没有沼气发酵池时天然气是终点，有发酵池时终点改成有机废料。钻井和发酵池可以同时存在。机器人或高科没有生产建筑时是原料，有则继续倒推。已安装且在有效配送内的磨损加进消费并加下划线。效率行用这些规划数字，不把住宅算进消耗。

算法只读取已经建好的工厂和建筑配方，不修改工厂配方、生产速度、住宅消费、市场统计或资源库存。

最终产物：没有别的工厂配方把它当原料，或者本区有生产建筑的工业机器人、高科技工具、有机废料。同一条产线消耗自己的产出不算。产量为蓝色。产量大于消费且多出的部分大于该区单座最高产量时为绿色。选中地区时，没有生产建筑的原矿排在最前，最终产物排在最后，其余在中间。未选地区不改顺序。效率行的三个数字有换行提示。

### 建筑面板上的每分钟配方

点开工厂后，面板里“生产：”后面用物品图标和数字显示这座建筑按当前效率计算的每分钟消耗和产出。效率为 0 时这些数字是 0。存储行不变，也不改配方、库存或生产速度。

### 电力范围分色

打开可视化并选择电力时，同一电网的供电范围使用同一种颜色，没有连在一起的电网使用不同颜色。最大的一组仍是原版淡黄色。建筑、输电线和供电结果都不改。

颜色只在内存中计算，不写入存档。原版那张把所有范围涂成同一种黄的全图贴花会关掉，改由每座供电建筑自己的范围圈显示。

### 从生产概况定位生产建筑

在生产概况里单击某个资源图标后，地图切到白色总览，生产该资源的建筑显示为绿色。双击则把需要该资源的工厂和住宅显示为蓝色。再点一次同一种操作会取消，其他视图都关掉之后，右键或 Esc 也会取消。选中区域时只标出该区域内的建筑。没选中的资源图标变成灰度，选中的保持原色。鼠标放在图标上会说明单击、双击和退出。点选电力、道路等可视化按钮时也会恢复。供电建筑算作电力的生产建筑，需要供电的工厂和住宅算作电力的需求建筑。

### 按产物查看生产建筑

打开可视化后，面板下方列出全部工厂配方产物。当前没有建筑在生产的物品数量为 0。点选一项后，生产该物品的建筑显示为绿色，其余建筑变为灰色。再点一次取消。点选电力、道路等原有可视化按钮时也会取消，并回到对应视图。

这个列表只读配方，不修改生产或库存。

## 兼容性

- 无持久化业务状态；
- 不修改模拟结果；
- 兼容等级：A（原版存档安全）。

## 技术说明

程序集、配置名和根命名空间均为 `InfraSpaceProductionInsights`，入口类型为 `InfraSpaceProductionInsights.ProductionInsightsMod`。
