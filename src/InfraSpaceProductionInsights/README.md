# InfraSpace Production Insights

增强原版生产概览面板的只读分析 Mod。

## 功能

### 隐藏全零行

查看地区数据时，如果某项资源显示的就业、生产、消费均为零，则隐藏该行。全局视图不做此筛选。

### 列表合计

生产概况列表最后一行显示当前可见行的合计：就业人数、生产、消费。就业显示成“总数/每座建筑”，例如 10/5 表示一共 10 名工人，平均每座生产建筑 5 人。鼠标放在工人列表标题上会看到同样的说明。优先级滑条不参与合计。地区视图里被隐藏的全零行不计入。最终产物开关打开时，消费合计使用反推后的需求数字，并在合计下面再加一行效率：工人列是每生产 1 个最终产物平均占用的工人，生产列是平均耗电，消费列是平均占用的建筑。分母是当前可见的最终产物产量，分子含中间产物。生产和消费把不同物资在面板上的数字直接相加。

每个资源图标底部显示正在生产它的建筑数量，合计行的图标位置显示这些数量之和。未选择区域时按全图计数；选中区域后只计该区域内的建筑。供电建筑计入电力。同一座建筑若产出多种物资，会分别计入每种物资。

### 最终产物需求

地区筛选启用时可打开“最终产物”开关。Mod 先找出这个地区的最终产物建筑，按配方往上游倒推原料需求，并覆盖面板中的消费显示。效率只改变生产速度，不改变每一级要几份原料，所以中间建筑的效率、开工和数量都不参与。高科技工具这类已安装产率加成按配方速度计入。鼠标放在蓝色最终产物上可以看到这套倒推说明。某一级工厂一座都还没建时，仍用这种物资的配方继续往下推；这一级当前没有产量，消费列照样显示反推出来的需求。有机废料按原矿输入，只记下游需要多少，不看产出它的配方。选中地区时它和矿产排在一起。

算法只读取已经建好的工厂和建筑配方，不修改工厂配方、生产速度、住宅消费、市场统计或资源库存。

工业机器人和高科技工具的升级每帧只扣耐久，原版不把这笔磨损写入生产概况的消费列，所以这两行的消费一直是 0。现在按有效配送覆盖补上：建筑落在正在配送该物资的配送中心范围内，中心能出车，建筑自己有入口，才按每座每分钟 0.048 计入。未选地区时按全图，选中地区后只计该地区。覆盖外或没有路的升级不计入。鼠标放在消费数字上可以看到这次计入的座数和合计。产量仍按原有规则补齐。选中地区后，最终产物按配方判断：本地区有工厂产出它，并且没有别的工厂配方把它当作原料。同一条产线消耗自己产出的部分不算，所以高科技工具不会因为车间自己用掉一部分就被当成中间产物。这样标出的最终产物产量为蓝色，鼠标放在蓝色数字上会说明原因，也不会因为富余变成绿色。效率行的分母仍按“有没有出现在任何配方原料里”计算，产线内部消耗也算原料，这个均耗数字不变。其余物资里，产量大于消耗、且多出来的部分还大于该地区目前产量最高的一座建筑时，产量数字显示为绿色，鼠标放在绿色数字上会列出产量、消费、多出的数量和单座最高产量。

选中地区时，矿产排在列表前面，按配方认定的最终产物排在最后，高科技工具和工业机器人也在其中。其余物资仍按游戏原来的顺序。未选地区时恢复游戏原来的顺序。

效率行和「最终产物」开关的说明会换行。鼠标放在效率行的三个数字上，可以看到计入的建筑或物资、分子、分母和当时的算式。

### 建筑面板上的每分钟配方

点开工厂后，面板里“生产：”后面用物品图标和数字显示这座建筑按当前效率计算的每分钟消耗和产出。效率为 0 时这些数字是 0。存储行不变，也不改配方、库存或生产速度。

### 电力范围分色

打开可视化并选择电力时，同一电网的供电范围使用同一种颜色，没有连在一起的电网使用不同颜色。最大的一组仍是原版淡黄色。建筑、输电线和供电结果都不改。

颜色只在内存中计算，不写入存档。原版那张把所有范围涂成同一种黄的全图贴花会关掉，改由每座供电建筑自己的范围圈显示。

### 从生产概况定位生产建筑

在生产概况里单击某个资源图标后，地图切到白色总览，生产该资源的建筑显示为绿色。双击则把需要该资源的工厂和住宅显示为蓝色。再点一次同一种操作会取消。选中区域时只标出该区域内的建筑。鼠标放在图标上会说明单击和双击的用途。点选电力、道路等可视化按钮时也会恢复。供电建筑算作电力的生产建筑，需要供电的工厂和住宅算作电力的需求建筑。

### 按产物查看生产建筑

打开可视化后，面板下方列出全部工厂配方产物。当前没有建筑在生产的物品数量为 0。点选一项后，生产该物品的建筑显示为绿色，其余建筑变为灰色。再点一次取消。点选电力、道路等原有可视化按钮时也会取消，并回到对应视图。

这个列表只读配方，不修改生产或库存。

## 兼容性

- 无持久化业务状态；
- 不修改模拟结果；
- 兼容等级：A（原版存档安全）。

## 技术说明

程序集、配置名和根命名空间均为 `InfraSpaceProductionInsights`，入口类型为 `InfraSpaceProductionInsights.ProductionInsightsMod`。
